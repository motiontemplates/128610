How it works

  • Declared runtime profile: html-canvas/1.
  • Editable inputs are mapped through the template parameter schema and preset to its existing animation project.
  • The declared timeline has a fixed duration; new content fits its existing scene order and timing.

The documented output is 1920 × 1080, 60 fps. The public demo is 57 seconds. Use the actual package parameter bounds; extra materials do not automatically create extra scenes. Changing scene order, output duration or engine; these are not parameters of this fixed native arrangement. Declaring arbitrary copy length or every product topic suitable without actual layout and semantic review.
